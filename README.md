# নিরাপদ ঢাকা — খবর সংগ্রহ

প্রতি ঘণ্টায় GitHub Actions অনলাইন খবর (Google News RSS) থেকে ঢাকার অপরাধের খবর খোঁজে।
শব্দ দিয়ে ছেঁকে GitHub Models-এর ফ্রি AI দিয়ে এলাকা আর ঘটনার ধরন বের করে,
তারপর "নিরাপদ ঢাকা" অ্যাপের সার্ভারে পাঠায়। শুধু শিরোনাম, উৎস আর লিংক যায়, পুরো খবর নয়।

- `collect.mjs` — মূল স্ক্রিপ্ট (Node 20, কোনো প্যাকেজ লাগে না)
- `areas.json` — ঢাকার ৭৫টা এলাকা আর তাদের বিকল্প নাম (খবরে যেভাবে লেখা হয়)
- `.github/workflows/collect.yml` — প্রতি ঘণ্টায় চালায়

কোনো secret লাগে না: GitHub Actions-এর নিজের সই করা পরিচয়-টোকেন (OIDC) দিয়ে সার্ভার বোঝে খবরটা এই রিপো থেকেই এসেছে।
হাতে চালাতে: Actions → Collect Dhaka crime news → Run workflow (dry_run = 1 দিলে শুধু দেখাবে)।

নতুন এলাকার নাম যোগ করতে `areas.json`-এর `aliases`-এ লিখুন (সংখ্যা ইংরেজিতে, যেমন "মিরপুর 10")।
